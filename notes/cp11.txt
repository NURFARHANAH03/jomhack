The Core Difference
Git is for standard Code History (Development Time):

Git tracks changes to your source code over time (e.g., who wrote a function, when it was modified, and what code changed).

It answers: "How did my code look last week, and who changed line 42?"

Logging is for Application Activity (Runtime):

Logging tracks what happens while your program is actually running (e.g., user sign-ins, system errors, database connection failures, or rejected inputs).

It answers: "What happened in production at 3:00 AM when a user tried to register?"
