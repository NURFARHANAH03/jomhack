>How ?. prevents a crash: Because of ?., JavaScript checks if post.author exists. Since it is undefined, it stops right there and safely evaluates the whole expression to undefined instead of throwing an error.
>The ?? operator is called Nullish Coalescing. It acts as a fallback default value handler.
It checks the left side: if the left side evaluates to either null or undefined, it uses the right side value ("Unknown") instead.
